🛡️ Project Architecture & Viva Demonstration Workflow

This integrated web application provides an authentic, dual-state testing ground for security evaluation and remediation. Each team member's module implements:

  • Dual Execution Engine: Real-time toggle between Vulnerable Mode (faulty concatenation/missing checks) and Mitigated Mode (hardened defensive implementation).
  • Side-by-Side Code Inspection: Precise source code paths showing the flawed function versus the secure refactored logic.
  • One-Click Exploit Injection: Ready-to-run academic payloads to demonstrate exploitation live during video recordings and individual viva defense.
  • Mitigation Proof: Shows the identical payload fail or get safely blocked with appropriate security controls in Mitigated mode.
  • Lecture Slides Theoretical Coverage: Summaries of all alternative mitigations (prepared statements, allow-lists, least-privilege, safe DOM sinks, CSP, SameSite tokens).
